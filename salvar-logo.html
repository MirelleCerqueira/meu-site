Como salvar como JPEG:

  1. Clique com o botão direito sobre o logo (fundo branco ou escuro)
  2. Escolha Inspecionar
  3. Clique com o botão direito no elemento destacado no código
  4. Escolha Capture node screenshot
  5. O arquivo PNG é salvo na sua pasta de Downloads
  6. Abra o PNG no Paint e salve como JPEG
